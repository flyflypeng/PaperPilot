# Strict

Use this mode when you want the smallest, highest-confidence feed.

- Institution tiers: Tier S is highest priority, Tier A is accepted when topic relevance is strong
- Tier B/C institutions: normally filtered out unless later external signals are added and are very strong
- Unknown institutions: not kept by default
- Result size: smallest candidate pool, intended to reduce downloads and review load

Best for focused daily reading when quality matters more than recall.
